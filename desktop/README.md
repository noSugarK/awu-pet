# Awu Pet 嗷呜桌宠

> Designed by **黄小B** · Powered by **noSugarK**

Awu Pet（嗷呜桌宠）是一款桌面宠物，默认角色是一二和布布，可以在右键菜单「🔄 角色」里切换角色（换角色后菜单只显示新角色能做的事）。它们站在你的任务栏上，眼睛跟着鼠标转，没人理时自己散步、吃面、喝奶茶、跳舞、抱抱，你离开电脑就趴下睡觉。它们还是会吃文件的回收站：把文件拖到熊身上，或者在资源管理器里右键「请一二删除」，它们就会跑过去张开大嘴吃掉——文件进系统回收站，随时可以找回。

Rust + Tauri v2。熊的画法和动作来自 `../docs/js/pet.js`（和网站同一份代码），Rust 负责透明置顶窗口、点击穿透、托盘 / 右键菜单和回收站。

## 功能

- 站在任务栏上，没人理时自己散步、吃面、喝奶茶、跳舞、抱抱；你离开电脑会趴下睡觉。
- 眼睛跟着鼠标；点它、拖它、把两只拖到一起抱抱。
- **把文件 / 文件夹拖到熊身上**：它张开大嘴等着，松手就吃掉（移进系统回收站，可以找回）。
- **资源管理器里右键文件 →「请一二删除 / 请布布删除 / 请一二布布删除」**：熊冲到那个文件旁边把它吃掉（Windows 11 在「显示更多选项」里）。出现哪几项跟着当前显示的角色走。
- **右键熊或托盘图标**：动作、外观（显示哪只、大小、搭配）、回收站（吐出来 / 打开 / 清空）、设置（置顶、自己玩、开机自启、文件右键菜单、关于）、隐藏、退出。
- 托盘图标左键：隐藏 / 显示。

## 开发

需要 Rust stable 和 Tauri CLI：

```bash
cargo install tauri-cli --version "^2"
```

在 `desktop/src-tauri` 下运行：

```bash
cargo tauri dev
```

打包安装程序：

```bash
cargo tauri build
```

改熊的样子或动作：编辑 `docs/js/pet.js` / `docs/css/pet.css`，网站和桌宠同时生效。
