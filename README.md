# Awu Pet · 嗷呜桌宠

> Designed by **黄小B** · Powered by **noSugarK**

**住在任务栏上的桌宠：会陪你玩，还会帮你“嗷呜”一口吃掉文件。**

> 原名 YierBubu-Pet。旧版装过的话，新安装包会先把旧版卸掉；设置、位置和今日食谱都会保留。

Awu Pet（嗷呜桌宠）是一款桌面宠物，默认角色是一二和布布，可以在右键菜单「🔄 角色」里切换角色（换角色后菜单只显示新角色能做的事）。它们站在你的任务栏上，眼睛跟着鼠标转，没人理时自己散步、吃面、喝奶茶、跳舞、抱抱，你离开电脑就趴下睡觉。它们还是会吃文件的回收站：把文件拖到熊身上，或者在资源管理器里右键「请一二删除」，它们就会跑过去张开大嘴吃掉——文件进系统回收站，随时可以找回。



- **下载桌宠**：[GitHub Releases](https://github.com/noSugarK/yierbubu-pet/releases)（Windows / macOS / Linux）
- **互动网页**：[`docs/index.html`](docs/index.html)，直接用浏览器打开即可；部署在 GitHub Pages。
- **桌宠软件**：`desktop/`（Rust + Tauri v2）。可切换形象，没人理的时候自己玩，还能把文件拖给它"吃掉"（移到系统回收站，可找回）。
- **宣传视频**：`video/`（Remotion），横版 1920×1080 + 竖版 1080×1920，`cd video && npm i && npm run render` 输出到 `video/out/`。
- **设计文档**：[`DESIGN.md`](DESIGN.md)，包括角色规格、动作 / 道具调研、网站部署、桌宠架构和里程碑。

## 能做什么

- **文件投喂**：图片、音乐、视频、压缩包、文档、文件夹……吃到不同东西有不同反应，还有「今日食谱」
- **像活的一样**：按性格自己玩，夜里犯困，两只会互相戳醒、追着玩，全屏打游戏时自动躲开

## 网页里能做什么

移动鼠标（它们会看你）· 点击 · 连点 · 拖着跑 · 拖到一起拥抱 · 双击空白处 · 思考 / 跳舞 / 害羞 / 睡觉 · 吃面 / 奶茶 / 送花 · 墨镜 / 围巾搭配

## 部署网站

Settings → Pages → Deploy from a branch → `main` / `/docs`。

## 发布新版本

改好 `desktop/src-tauri/tauri.conf.json` 里的 `version` 后，推送同名 tag（如 `v0.1.0`），GitHub Actions 会自动打包三个平台并发布到 Releases。
